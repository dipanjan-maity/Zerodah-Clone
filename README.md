# Zerodha Clone

A Zerodha-inspired trading platform built using the MERN Stack.

### 📊 Dashboard

## 🛠️ Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- Bootstrap
- Axios
- bcryptjs

## ✨ Features

- User Registration
- User Authentication
- Holdings
- Positions
- Buy Orders
- Sell Orders
- MongoDB Atlas Integration
- REST API
- Responsive UI
